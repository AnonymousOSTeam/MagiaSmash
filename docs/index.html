What it is

A focused arena fighter

MagiaSmash is a small, complete combat prototype: one arena, one player, five escalating waves, and a combat system built to be tuned entirely from config files.

⚔️

Deliberate combat

Light and heavy attacks with startup, active and recovery frames, hitstop, hitstun, lunge and directional knockback. A three-hit light chain rewards aggression.

👤

One fighter system

A single C++ Fighter class powers every combatant — player and enemies alike — so behaviour stays consistent and each character is just a config section.

🌊

Five waves

Enemies spawn from alternating sides with a per-wave difficulty scale. Health carries between waves: clear all five to win.

📜

Data-driven content

Fighters, moves, enemies, waves, effects, colours and UI all live in MagiaSmash.ini. Rebalance without recompiling.

🐍

Python director

Scene setup, wave spawning, victory and restart flow live in MagiaSmash.py, driving the match each frame.

✨

Feel

Hit sparks, slash arcs, dash pulse trails, camera shake and SDF-glow UI text — all defined as data, no code edits required.

How a match plays

Clear five waves, keep your health

Each wave spawns a set of foes from one side of the arena. You keep the health you have left — there are no pickups, only skill.

1
Two Chiropteran
Warm-up. Both foes from the left.
2
Three Chiropteran
Same fodder, more of them, from the right.
3
First big foe
A BigChiropteran joins two regulars.
4
Crowd control
Four enemies at once, including a big one.
5
The finale
Two big foes and a regular — the real test.
