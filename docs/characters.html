How enemies fight

Enemy behaviour is data-driven by three keys carried on every Fighter:

  • AI — marks the fighter as computer-controlled.
  • AIAttackRange — how close it must be to swing (130 for a Chiropteran, 170 for a big one).
  • AIAttackDelay — the pause between attacks (1.5s vs 2.0s).

The big variant's DamageScale of 1.6 multiplies the shared Claw damage, so one small config value makes it meaningfully scarier.

Design note

Everything inherits

Config parenthood keeps the roster tiny to define. [Saya@Fighter] starts life with every base value and overrides only what makes her Saya.

; Base defaults shared by every combatant
[Fighter]
Health          = 100
MoveSpeed       = 600
JumpVelocity    = 1450
Gravity         = 3800
DashSpeed       = 1400
ComboList       = Light1 # Light2 # Light3
HeavyMove       = Heavy
AIMoveList      = Claw

; Saya inherits all of the above, then overrides a few keys
[Saya@Fighter]
RGB             = (0.95, 0.5, 0.8)
Health          = 120
MoveSpeed       = 620
IsPlayer        = true
Input           = PlayerControls
Team            = 0

; A big foe is just a Chiropteran with new numbers
[BigChiropteran@Chiropteran]
RGB             = (0.62, 0.12, 0.18)
Health          = 150
Size            = (130, 230)
DamageScale     = 1.6
AIAttackRange   = 170
