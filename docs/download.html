Install & run

Running the game

Three commands. The important part is where you run it from.

  1. Extract the archive

    The tar.gz contains a single top-level folder; unpack it anywhere.

    tar -xzf MagiaSmash-0.3.0-linux-x86_64.tar.gz
cd MagiaSmash-0.3.0-linux-x86_64

  2. Enter the bin directory

    The game resolves its configuration and resources relative to bin/, which sits beside data/. Launching from the wrong directory means no window.

    cd bin
./MagiaSmash

  3. Play

    Move with the arrow keys, attack with J and K, dash with Left Shift. Clear five waves to win. Press R to restart.

Do not move files around. The bundle must keep its layout — bin/ and data/ as siblings. orx looks for data/config/MagiaSmash.ini and loads Python and assets through ../data/… paths.

Requirements

What you need

System

  • Linux x86_64
  • An X11 display
  • OpenGL 2.1+

Libraries

  • libdl, libm, librt
  • X11 and GL (typically present)
  • orx runtime — included
